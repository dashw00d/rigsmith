# UI scenarios

Set `RIGSMITH_WORKSPACE` to a private workspace copy and run `npm run e2e` or `npm run e2e -- --only=smoke.steps --keep`. `E2E_CHARACTERS=id,id` selects the copied characters; by default the first folk and first non-folk are copied. `--keep` retains the isolated workspace and prints its path. The server picks a free port and never binds 5180, 5181 or 5190. Each scenario gets a fresh headless Chrome page at 1280×800, cleared storage, and the requested character and step. The run writes screenshots under `.work/e2e/<run>/` and fails on browser console errors or uncaught exceptions unless `allowErrors: true` is set on that scenario. Scenarios have 90 seconds each, the run 10 minutes.

The workspace copies settings, game, and characters, links only `library/{clips,creatures,manifest.json,meta}`, and checks the source linked files' mtimes, sizes and inodes on exit. Never write a linked library file in place: write a new file and rename it. The copied settings point at a sandbox game repo. If the OS temp directory is on a different filesystem, the temporary workspace is made beside the source so hard links work; both locations are cleaned up by default. Symlinks in copied trees are rejected.

A file named `<area>.<name>.scenario.ts` default-exports `{ name, character?, step?, allowErrors?, async run(ui) { ... } }` satisfying `Scenario`. Prefer `{role: 'button', name: 'Save'}` for named controls; use `{testid: 'gear-row', id: gearId}` for repeated rows and `{testid: 'thing', within: {testid: 'dialog'}}` for scope. These select accessible roles/names through CDP or `data-testid`/`data-id`, never presentation classes.

`ui.click`, `ui.rightClick`, `ui.clickAt(selector, x, y)` (element-relative CSS pixels), `ui.fill`, `ui.key`, `ui.press('ctrl+z')`, `ui.exists`, `ui.text`, `ui.count`, `ui.waitFor(selector | r => boolean, ms?)`, `ui.shot(label)` are asynchronous. `ui.app()` returns a serializable snapshot of app selection, characters, step and drawer. `ui.eval((r, arg) => ..., arg)` executes a self-contained function against the dev-only `window.__rigsmith` hook; pass external values as JSON arguments, not captured variables. Use it to assert live state, not CSS. Errors name the missing selector and nearby available testids or accessible names.
